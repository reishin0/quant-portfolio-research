| Improvement | Assessment | Next defensible change |
|---|---|---|
| 1. Refresh inputs together and retain vintages | **Yes; implemented for this refresh.** Mixed release dates and historical revisions are now observable, rather than hidden. | Continue immutable dated acquisitions, per-source coverage/availability checks and separate revision attribution. Do not forward-fill unpublished factor observations. |

If exact matching is infeasible, disclose it rather than naming the result exactly risk matched. |
| 5. Calibrate forecast and conversion uncertainty | **Yes, when suitable history exists.** The 10% forecast error and 2% basis error remain assumptions; the current quarter is unfinished. | Collect dated forecast vintages and completed outcomes; estimate errors on prior quarters only, validate interval coverage on later quarters, and shrink toward a conservative default when samples are sparse. Never fit Omega to this quarter's portfolio P&L. |

The evidence does **not** support changing the portfolio to chase the latest winning method. The next improvement is a better observation and decision record, followed by a separately registered horizon/risk/calibration study.

## Reproduction

From the repository root, in the established portfolio environment:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -q
.venv\Scripts\python.exe forward_evaluation.py
.venv\Scripts\python.exe run_updated_analysis.py --inputs data/refresh_20261016
```

The last command creates a new executed notebook, HTML report, amendment record and execution receipt under `outputs/updated_report_<UTC timestamp>/`. It verifies both the new inputs and the frozen protocol before execution, and verifies the frozen protocol again afterward. New raw acquisitions require a new directory; provider data can be revised on subsequent downloads.

`refresh_inputs.py collect --directory data/<new-date> --end <exclusive-date>` obtains source files; `prepare` derives paired valuations, factors and cash. Preparation requires the established numerical environment plus `openpyxl` for read-only issuer workbook extraction. This run used the bundled document Python for that extraction. Raw vendor files remain local; their hashes are retained without asserting redistribution rights.
