## Prototype and architecture

`specification.json` declares the bounded experiment. `prototype.py` reads only saved bars. It uses the existing NumPy/pandas/SciPy stack and the already installed `hmmlearn` library in the inspected AutoTrade Python environment; no new framework was introduced.

1. A separate acquisition adapter stores provider bars, timestamps, retrieval time and raw-response hashes under `data/intraday_20261016/`.
2. Bar end is the assumed availability time. This is an optimistic research convention, not observed provider latency. Missing bars are not filled. Timezone-aware conversion uses America/New_York and UTC; all selected dates are full regular NYSE sessions.
3. Supporting observations include session-open moves, five-/thirty-minute changes, previous-close opening gaps, breadth and rolling equity volatility. Gaps and thirty-minute changes are diagnostic features, not outcome-tuned additions to the rule.
4. The state combines equity stress with IEF's session-open price direction. All replay states have `_PROXY` labels. The separate direct-yield interface requires fresh two- and ten-year changes, but has only fixture tests because no measured intraday yield panel was admitted.
5. Missing, future, stale (over 90 seconds) or wrong-session required observations return UNKNOWN and no new research risk permission. The independent equity control can remain available when only the bond observation is missing. Agreement scores are explicitly not probabilities.
6. HMM fits use up to 1,500 completed prior observations with train-only mean/scale. One fit per evaluation session; recursive filtered posteriors only. Missing test minutes advance the hidden chain without a new emission. Overnight duration is not modelled. State identity is chosen by fitted return mean; the resulting posterior is not a calibrated probability of the forward stress label.
7. No BL expected return enters an intraday rule. BL-with-intraday-control versus control-only has not been tested; inserting an incompatible monthly forecast would not be a valid ablation. The existing portfolio prior/scenario controls assess the slower question separately.

State outputs include support values, decision timestamps, assumed freshness, agreement semantics and research-only permissions. Source receipt details are retained in the input manifest. The replay cannot prove real-time freshness because it lacks historical arrival timestamps. Curve changes, covariance between measured equity and yield changes, and actual execution costs remain unimplemented pending qualified data.

October 1–9 provides initial development history; October 12–15 are evaluated chronologically with prior-only refits. Later sessions may use earlier completed evaluation observations, as declared. These are four exploratory evaluation dates, **not four untouched confirmation dates**.

There are **1,403 common eligible minutes** out of 1,560 regular-session minutes. Warm-up, missing bars and the final forward-label window account for exclusions. The label is SPY falling more than 0.2% over the next 15 complete minutes. Only **eight positive minute labels** occur, several overlapping; this is not eight independent macro events.

The macro rule adds six false-positive minutes versus the broad guard with no additional true positives. The HMM's many alerts mostly do not correspond to the specified short-horizon loss. On October 14 its fitted return means barely separate while volatility differs substantially; calling the lower-mean state “bear” does not ensure it represents directional stress. The combined rule misses every positive label. No thresholds were changed after seeing these results.

On October 14, the first positive forward label begins at 09:51. The early rule alerts two minutes later; the guard and macro rule alert 47 minutes later. This is a descriptive alert-minus-label timing statistic, **not measured CPI-response latency**. October 15's first early alert precedes that day's much later first positive label by 245 minutes, illustrating why first-alert timing alone is misleading. Full per-day precision, recall, timestamps, coverage and changes are exported.

### Economic diagnostic, separately interpreted

Compare 43 identical, non-overlapping hypothetical 30-minute SPY opportunities. Decide at time t, enter at the next bar close, exit 30 minutes later; abstain when a filter flags stress. Close-to-close values are not bid/ask executable fills. Costs below are assumptions per side, not measured slippage. All four evaluation sessions are aggregated; no annualization or significance claim.

| Rule | Accepted / 43 | Net return at 2 bp each side | Net return at 5 bp each side |
|---|---:|---:|---:|
| Accept every opportunity | 43 | -1.3238% | -3.8379% |
| Broad guard | 36 | -0.9996% | -3.1158% |
| Early equity | 35 | -0.8958% | -2.9560% |
| Bond-price proxy | 36 | -0.9996% | -3.1158% |
| Adapted HMM | 15 | -0.8946% | -1.7829% |
| Combined | 43 | -1.3238% | -3.8379% |

Every rule loses under both cost assumptions. The macro and broad-guard paths are identical at these sampled opportunities. The HMM's smaller loss largely coincides with taking fewer trades; it does not prove directional skill. The combined rule's four alert minutes do not coincide with sampled entry decisions. This artificial schedule is not the user's native strategy or a replacement backtest. Native fills, shorts, inventory and missed-opportunity economics still require the original trade receipts and a fixed matched replay.
